### Swapping clips

The file sources only need a URL, so any clip swaps in by replacing the `.ogg` asset
and its `import … ?url` in `src/model/SimModel.ts`. Prefer **Ogg Vorbis / Opus / WAV /
MP3** (browser `decodeAudioData` does not support Ogg **Speex**). Record any new
attribution in this file.
